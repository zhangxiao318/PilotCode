# 2026-05-07 开发日志

## 当日主要变更

- **Web UI 功能增强**：
  - 新增文件浏览器（File Explorer）和 Git 状态面板（Git Status Panel），支持在 Web 界面中直接浏览项目结构和查看 git 变更
  - 重写 Markdown 渲染器：支持 heading、list、paragraph 等基础元素，后续补充 table 支持
  - 新增发送锁（send lock）防止用户重复提交消息
  - slash commands（如 `/index`、`/format` 等）接入流式协议，解决 Web UI 中斜杠命令挂起问题
  - `send_to_client` 新增 timeout guard，防止 Windows 下 WebSocket 挂起

- **Web UI 稳定性与兼容性**：
  - 工具调用强化：在 `_should_use_tools` 中检测编译错误并强制触发 tool calls；当 LLM 拒绝使用工具时发出警告
  - 移除每个 tool 执行时 noisy 的 AskUser debug log
  - Agent 输出禁用 ANSI 转义序列，改用 ASCII box，防止 Web 和 Windows 环境下乱码
  - `context_archive` 使用 uuid 生成唯一 entry_id，修复 Windows 下排序不稳定问题

- **编排器与错误处理**：
  - 修复编排器处理 LLM JSON 时 `worker_type` 非字符串、字段为数字类型导致的解析失败
  - 错误处理模块支持 provider 返回的 integer 类型 `error.code`

- **测试修复**：
  - `test_detect_shell_windows` 补充 mock `shutil.which`，防止 Linux CI + Python 3.12 环境下崩溃

> 涉及 20+ 个文件，800+ 行变更。
