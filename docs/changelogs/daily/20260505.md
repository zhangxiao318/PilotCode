# 2026-05-05 开发日志

## 当日主要变更

- **统一 Prompt 架构**：
  - 新增 `prompts.py` 服务模块，统一维护 planner / worker / verifier 三类 prompt
  - 按模型能力（强/中/弱）和任务类型动态选择 prompt 模板
  - 消除散落在 adapter / repl / orchestrator 中的硬编码 prompt 字符串

- **三阶段 Agent 架构升级**：
  - 将原有单体 worker 拆分为 explorer（分析）、coder（实现）、verifier（验证）三种 Agent
  - 各 Agent 拥有独立的 system prompt、tool 集合和记忆空间
  - MissionAdapter 根据任务类型自动路由到对应 Agent
  - 新增 `agent_memory.py` 持久化 Agent 级别的执行经验

- **Plan 模式决策鲁棒性**：
  - 修复 `classify_task_complexity` 过度触发 PLAN 模式的问题
  - 引入更严格的复杂度评分阈值和元特征检测（代码修改量、文件数、跨语言）
  - 新增 comprehensive test coverage（plan mode 单元测试 12 个）

- **环境检测器**：
  - 新增 `environment_detector.py`：自动检测项目类型（Python、Node.js、Rust、Go、Java、C/C++）
  - 根据检测到的语言动态注入编译/构建指导到 worker prompt
  - `TestRunnerVerifier` 升级为 language-aware verifier，支持 C/C++ 编译检查
  - 修复 task tool 在 C/C++ 项目中的误用问题

- **语言指导精确化**：
  - 移除之前对所有 worker 的 blanket `language_guide` 注入（导致 prompt 膨胀）
  - 改为仅在检测到对应语言时才注入相关编译/测试指令
  - 解决多语言混合项目中 prompt 互相干扰的问题

> 涉及 15+ 个文件，600+ 行变更。
