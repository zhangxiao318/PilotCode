# 2026-05-14 开发日志

## 当日主要变更

- **QueryEngine 重构（五大子管理器提取）**：
  - 将臃肿的 `QueryEngine` 拆分为 5 个专职子管理器：
    - `SessionManager`：会话生命周期与状态管理
    - `MessageParser`：消息解析、归一化与格式转换
    - `PromptBuilder`：prompt 组装与动态边界注入
    - `CompactionManager`：上下文压缩策略与调度
    - `TokenManager`：token 估算、预算分配与基线测量
  - 更新 `__init__.py` 统一导出接口，保持向后兼容

- **上下文压缩管道升级**：
  - 实现五层渐进式压缩管道（five-layer graduated compaction pipeline）：
    1. Tool result 清理（Microcompact）
    2. 旧消息摘要化（Session memory）
    3. 侧链归档（Sidechain transcript）
    4. 结构化压缩（Full compact）
    5. 紧急截断（Emergency truncation）
  - 新增 fresh-session token 基线测量：在会话启动时测量空上下文 token 占用，作为后续预算计算基准

- **工具系统升级**：
  - 统一 Todo/Task 工具：支持持久化、resume 恢复、LLM 自动触发提示
  - 基于权限模式（permission mode）的工具预过滤：根据用户配置的安全级别动态筛选可用工具
  - 子代理对话侧链归档（sidechain transcript）：子 Agent 的完整对话自动归档，避免污染主上下文

- **索引与存储修复**：
  - 修复 ghost-hash bug：解决 indexer 中哈希冲突导致文件索引不完整的问题
  - VectorStore 在 `add` / `add_many` / `delete_by_file_path` 后 eager 重建 numpy 矩阵
  - 修复 async git 操作、WebSocket 稳定性、`/stats` 跟踪和 cwd 解析问题

- **代码质量**：
  - ruff + black lint 修复：移除未使用 import，修复 E402/F541/F841
  - 修复 `remove_file` 鲁棒性并更新统一 Todo 工具相关测试
  - 避免在线程内调用 `asyncio.run`，修复 VectorStore 矩阵重建测试
