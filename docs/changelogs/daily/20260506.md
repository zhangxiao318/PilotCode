# 2026-05-06 开发日志

## 当日主要变更

- **P-EVR 编排器稳定性修复（核心）**：
  - **死锁修复**：`_enqueue_ready` 中 `launched` 标志未在 while 循环每次迭代时重置，导致 `_max_workers > ready_tasks` 时无限循环；同时修复 `_ready_cache` 在任务启动后未失效的问题
  - **动态并发**：新增 `_adjust_concurrency()`，根据队列深度和平均完成时间动态调整 `_max_workers`（本地模型默认 1-2，远程 API 默认 3-5，上限 8）
  - **上下文预算拆分**：并发任务运行时，每个任务自动分配 `mission.context_budget // N`，防止本地模型 OOM 和远程 API 上下文爆炸
  - **Rework Retry 调度**：`get_ready_tasks()` 现在返回 `IN_PROGRESS` 状态的任务，确保 `_smart_retry` 后 NEEDS_REWORK → IN_PROGRESS 的任务能被正确重新调度（此前因 PENDING-only 检查导致主循环空等死锁）
  - **取消机制完善**：`cancel_mission()` 现在也会处理 `IN_PROGRESS` 任务（设置 `cancel_event` 并 transition 到 CANCELLED）；`action_copy` 在 mission 运行期间转为取消 mission；新增 Escape 键中断 mission 绑定
  - **验证短路**：`_verify_task` 在 mission 取消后立即返回，不再执行 L1/L2/L3 验证浪费资源
  - **Worker 死锁修复**：防止 P-EVR worker 因状态机竞态和 DAG 同步问题导致的死锁和挂起

- **Token 计算与上下文管理**：
  - **三层上下文管理**：新增 `ContextArchive` + `ContextCommands`，支持 `/context list|search|recall` 和 `/memory` CLI 命令
    - Microcompact：清除旧 tool results
    - Session memory：持久化结构化摘要到 `.pilotcode/context/session_memory.json`
    - Full compact：智能压缩并归档历史消息到 `compact_*.json`
  - **Token 估算改进**：使用 `api_total` 作为基准 + 10% 安全边距；自动检测提供商以调整 CJK 字符比例；提升启发式准确度
  - **Anthropic cache token 归一化**：将 Anthropic API 返回的 `cache_creation_input_tokens` / `cache_read_input_tokens` 正确映射到内部 token 统计

- **TUI 体验优化**：
  - 新增 `Ctrl+C` / `Escape` 中断运行中的 mission
  - mission 结束后自动清理 `_current_mission` 状态，防止重复取消
  - 移除重复的 `worker:text_delta` / `worker:turn_complete` 事件处理代码
  - 目标目录不存在时向 LLM 注入明确的 "do-not-cd" 指令

- **认证与探测**：
  - `_probe_backend_limits` 现在携带 `Authorization: Bearer {api_key}` 请求头，修复 LiteLLM Proxy 等需要 API Key 的 `/v1/models` 和 `/props` 端点返回 401 的问题

- **用户报告修复**：
  - `_extract_target_path` 不再将 URL 误判为 Unix 路径（如 `/api.openai.com/v1`）
  - 测试 `test_remote_model_uses_models_json` 同步 `models.json` 中 openai 的 `max_tokens=16384`
  - TUI 大段粘贴文本显示为 `[Pasted text #N +M lines]` 占位符，提交时自动还原原始内容

- **代码审查修复**：
  - Orchestrator 空 workers 取消路径返回明确的 `{"success": False, "error": "Cancelled by user"}`
  - Adapter `_tool_semaphore` 提升为实例变量，避免 while 循环内重复创建导致并发限制失效
  - ContextArchive IO 异常不再静默吞掉，改为 `logger.warning`
  - Ctrl+C 绑定描述更新为 "Copy / Cancel Mission"
